# Support

This 0.1.0 source candidate has no public support channel yet. A public
release must provide an issue tracker or contact route and identify supported
operating systems and package versions from its qualified build matrix.

When reporting a reproducible CLI problem, include the CIX version, operating
system and architecture, command line, input size, archive magic/version, and
the exact error text. Do not attach confidential input data unless an agreed
private channel exists.
