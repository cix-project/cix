# Support

This repository is a preparation scaffold. No supported CIX product release or
response-time guarantee is available yet.

Use GitHub Discussions for general questions and the bug form for reproducible
defects once a release is available. Include the version, platform, command and a
minimal non-sensitive reproduction. Do not upload credentials, private customer
data or confidential archives. Security vulnerabilities belong in private
vulnerability reporting as described in SECURITY.md.

Maintainers may acknowledge requests or link documented troubleshooting. Delivery
dates and feature acceptance are confirmed separately. Related reports may be
linked as duplicates while preserving useful evidence and legitimate feedback.
