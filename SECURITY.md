# Security policy

No CIX product version is published or supported by this preparation scaffold.
Supported release lines will be listed here when releases begin.

Use the repository's **Security → Report a vulnerability** feature for private
reports. Include affected revision, reproduction steps, impact, and a minimal
sanitized example. Do not place vulnerabilities, credentials, exploit payloads
containing private data, or customer information in public issues or Discussions.

If private reporting is not yet available, wait for it to be enabled rather than
posting sensitive details publicly. No response-time commitment is implied during
repository preparation.

Maintainers should triage privately, reproduce in an isolated environment, agree
on a fix and coordinated disclosure, and publish an advisory when appropriate.
If a credential is exposed, revoke it through its issuing service; deleting the
file alone does not revoke it.
